# 飞尘工地

可在浏览器中实时运行、交互游览的三维体素建筑工地。模型以 **0.2m/voxel** 为统一尺度，全部程序化生成，无外部模型、贴图、字体或 CDN 依赖。

## 启动

### 完整源码版

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（默认 `http://127.0.0.1:5173`）。

```bash
npm test          # 作业状态机测试
npm run build     # 生成 dist/ 与根目录离线单文件
npm run preview   # 预览生产构建
```

### 离线单文件版

直接用现代浏览器打开根目录的 **`飞尘工地.html`**。Three.js、样式、程序与全部场景资源均已内嵌，不需要服务器或网络连接。

## 操作

- **全景（1）**：左键环绕，右键平移，滚轮缩放。
- **步行（2）**：WASD / 方向键移动，按住左键拖动视角，Shift 加速；从工地入口进入，带场地边界与主要障碍碰撞。
- **巡游（3）**：自动经过入口、材料堆场、塔吊、顶层作业面、西侧卸货区和土方区。
- **观察点**：左下角下拉菜单可直接前往吊装、堆场、屋顶、卸货等机位。
- **P**：暂停 / 继续。暂停会同时暂停时间、机械、工人和尘土，仍可操作相机。
- **H**：帮助。
- 时间轴可跳至一天中的任意分钟；流速 0.5×–8×，1× 表示现实 1 秒推进现场 1 分钟。

## 施工日程

- 06:00–07:00：工人进场，楼层工人乘升降机到达作业面。
- 07:00–17:30：塔吊吊装、叉车装卸、车辆运输、混凝土卸料、土方与楼层作业。
- 17:30–18:15：不再开始新周期；机械安全停放，楼层工人乘升降机下楼并离场。
- 夜间：门岗值守，办公区、道路与安全警示照明保留，无悬空货物。

手动跳时间会按目标时刻直接重建一致状态。施工循环使用确定性状态机，货物由吊钩、叉齿或车厢位置驱动；不依赖完整物理引擎。材料安装与补料采用简化的循环演出。

## 源码结构

```text
src/
  config.js                  场地尺度、布局、日程与配色
  simulation/operations.js   纯数据作业采样器
  render/
    voxel.js                 体素实例化构件
    world.js                 主楼、脚手架、道路与场地
    machines.js              机械及货物适配器
    workers.js               工人岗位、进场与撤离
    environment.js           日月、天空、阴影与夜间照明
    dust.js                  局部短寿命体素尘土
    camera.js                环绕、步行、巡游
  ui/ui.js                   时间轴与低干扰界面
scripts/build-standalone.mjs 完全离线 HTML 打包
```
